Legacy background & root cause summary
- Legacy code is a minimal demo: routing.py uses Dijkstra with two explicit bugs:
  - No negative-weight validation.
  - Nodes are prematurely marked visited (discovery vs finalization).
- Tests: the repo contains test_routing_negative_weight.py testing negative-weight behavior.
- Root-cause table (in short):
  - Functionality: Bad routing due to wrong algorithm/order & assumption mismatch -> see routing.py.
  - Reliability: No outbox & no retry/backoff for external calendar side-effect -> leads to inconsistent state across systems.
- High-priority fix path:
  - Replace Dijkstra with Bellman-Ford if negative edges allowed, or validate negative edges and either reject or detect cycles.
  - Introduce outbox for external side-effects (calendar) and have strong idempotency and replay.

Greenfield design highlights
- Functional boundaries:
  - API layer: receives appointment requests; returns appointment ID (idempotent).
  - Storage: persistent appointment store + idempotency table + outbox table.
  - Worker: background process or message-queue-based worker: consume outbox, call calendar, mark processed.
- Error handling:
  - Input validation + request_id for idempotency.
  - Synchronous try: do best-effort with retries & exponential backoff at API layer (short attempts).
  - Outbox: durable for eventual consistency when calendar is slow/out.
  - Compensation: left to domain-specific logic. For cancellations, issue another outbox event or Saga compensation.
- Interfaces:
  - POST /appointments — create appointment. Payload: AppointmentRequest. Required fields: `request_id`(UUID), `user_id`, `start_time`(RFC3339), `end_time`, `location`. Optional: `details`.
  - GET /appointments/{id} — retrieve appointment.
  - GET /outbox — list unprocessed outbox.
  - POST /outbox/process — manually trigger replay.
- Data: see `src/scheduler/model.py`

Migration & parallel run
- Shadow mode (dual-write) first; replay & reconcile results:
  - Dual-write: write to both legacy and new store.
  - Gather event differences and run reconcile script until differences fall to acceptable level.
- Read/write cutover: Use a traffic switcher behind gateway; start with 1% traffic to the new service and ramp-up.
- Rollback: switch back to legacy until outbox is drained; or re-enable dual writes.
