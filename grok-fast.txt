### 3.4 New System Design (Greenfield Replacement)

**Target State:**
- Capability Boundaries: Compute shortest paths in graphs with possible negative weights; detect negative cycles; maintain API compatibility.
- Service Decomposition: Single module (graph.py for data, routing.py for algo).
- Unified State Machine: Init (load graph) → Compute (run Bellman-Ford) → Success (return path/cost) / Failure (raise error).
- Idempotency/Retry/Timeout/Circuit-Breaker: Not applicable (synchronous computation); add timeout if graph is large.
- Compensation (Saga/Outbox): N/A (no transactions).

**Architecture and Data Flow:**
```
[JSON Input] → Graph Loader → Bellman-Ford Algorithm → [Path, Cost Output]
```
- Prose: Load directed graph from JSON edges array. Run Bellman-Ford: Initialize distances, relax edges |V|-1 times, check for cycles. Reconstruct path via predecessors.
- ASCII Diagram:
```
Start → Load Graph (adj dict) → Bellman-Ford:
  - Dist[all] = inf, Dist[start]=0
  - For i in 1..|V|-1: Relax all edges
  - Check for negative cycles
  → Goal? Return Path & Cost : Error
```
- Key Interfaces/Schemas/Validation:
  - Input JSON: {"edges": [{"source": str, "target": str, "weight": float}]}; Validation: weight is number, no self-loops assumed.
  - Output: Tuple[List[str], float]; Path non-empty, cost finite.
- Migration/Parallel Run: Replace routing.py; no cutover needed (stateless). For parallel: Feature flag in caller to switch algorithms; shadow traffic by running both and compare outputs.
- Rollback: Revert to old routing.py.
